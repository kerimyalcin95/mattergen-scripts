# MatterGen Scripts

A collection of Python scripts for downloading, analyzing, and benchmarking crystal structure datasets generated by MatterGen and comparing them with established experimental and computational materials databases.

The objective of this project is to perform a statistical evaluation of MatterGen-generated crystal structures by comparing their structural, crystallographic, and geometric properties with large reference datasets using a unified analysis pipeline.

## Features

### Dataset Download

- Download crystal structures from multiple materials databases.
- Support Materials Project and OPTIMADE-compatible databases.
- Download multiple chemical systems in a single execution.
- Store downloaded structures as CIF files.
- Automatically create the required directory structure.
- Skip already downloaded structures.

### Statistical Analysis

- Analyze CIF, XYZ, and EXTXYZ crystal structures.
- Compute descriptive structural statistics.
- Analyze crystallographic symmetry.
- Analyze local coordination environments.
- Analyze bond geometry.
- Analyze radial distribution functions (RDF).
- Export detailed CSV summaries.
- Generate publication-quality PDF and PNG figures.
- Support parallel processing using all available CPU cores.

### Benchmarking

- Compare MatterGen with experimental and computational materials databases.
- Compare structural distributions statistically.
- Compare crystallographic properties.
- Compare local atomic environments.
- Compare bond geometry.
- Compare radial distribution functions.
- Produce consistent outputs across all datasets.

Clone the repository:

```bash

cd mattergen-scripts
```

Install the required packages:

```bash

    pymatgen \

    mp-api \
    ase \
    numpy \

    scipy \
    matplotlib \

    requests \
    python-dotenv
```

Alternatively, install all dependencies using the provided requirements file:

```bash
pip install -r requirements.txt
```

## Materials Project API Key

Downloading data from Materials Project requires an API key.

Create a `.env` file:

**Linux / macOS**

```bash
cp .env.example .env
```

**Windows PowerShell**

```powershell
Copy-Item .env.example .env
```

Add your API key:

```text
MP_API_KEY=YOUR_API_KEY
```

The downloader automatically loads the key from the `.env` file.

Alternatively, specify it directly from the command line:

```bash
python 00_download_database.py \
    --database mp \
    --api-key YOUR_API_KEY
```

## Scripts

### 00_download_database.py

Downloads crystal structures from supported materials databases and stores them as CIF files using a unified interface.

#### Download Features

- Download crystal structures from multiple databases.
- Support Materials Project and OPTIMADE-compatible providers.
- Download one or more chemical systems in a single execution.
- Store all structures as CIF files.
- Automatically create the required directory hierarchy.
- Skip existing structures.
- Resume interrupted downloads.
- Display download progress.
- Generate download summaries.

#### Supported Databases

| Database | Type | Status |
| -------- | ------------ | :----: |
| Materials Project | DFT | ✅ |
| COD | Experimental | ✅ |
| OQMD | DFT | ✅ |
| JARVIS | DFT | ✅ |
| Alexandria | DFT / ML | ⚠ Experimental |

#### Output Structure

```text
data/
├── MaterialsProject/
│   ├── Al-O/
│   ├── Fe-O/
│   ├── Ti-O/
│   └── Y-Al-O/
├── OQMD/
├── COD/
├── JARVIS/
├── Alexandria/
└── MatterGen/
```

#### Example

```bash
python 00_download_database.py \
    --database mp \
    --chemsys Al-O Fe-O Ti-O Y-Al-O \
    --output ../../data
```

### 01_basic_statistics.py

Computes descriptive statistics for crystal structure datasets.

#### Supported File Formats

- CIF (`.cif`)
- XYZ (`.xyz`)
- EXTXYZ (`.extxyz`)

#### Computed Properties

For every structure:

- Reduced formula
- Number of atoms
- Number of unique elements
- Lattice parameter `a`
- Lattice parameter `b`
- Lattice parameter `c`
- Cell angle `α`
- Cell angle `β`
- Cell angle `γ`
- Cell volume
- Density
- Space group
- Structure validity

1. Download reference crystal structures from one or more supported databases.

3. Run the analysis pipeline on every dataset.
4. Compare structural statistics.
5. Compare crystallographic symmetry distributions.
6. Compare coordination environment distributions.
7. Compare bond geometry distributions.
8. Compare average radial distribution functions.
9. Compare statistical distributions between MatterGen and reference databases.
10. Evaluate how closely MatterGen reproduces the statistical characteristics of experimentally measured and computationally generated crystal structures.

## Roadmap

The benchmark currently evaluates the following statistical properties:

- Chemical composition
- Basic structural statistics
- Crystallographic symmetry
- Coordination environments
- Bond geometry
- Radial distribution functions (RDF)

Planned additions:

- Stability metrics
- Formation energy
- Energy above hull
- Band gap statistics

Future improvements include:

- Configurable plotting options
- Unified benchmark runner
- Shared plotting utilities
- Shared configuration file
- Improved statistical visualizations
- Additional comparison metrics

The primary objective is **not** to compare individual crystal structures. Instead, the benchmark statistically compares large collections of crystal structures generated by MatterGen with established experimental and computational materials databases to evaluate whether MatterGen reproduces realistic structural, crystallographic, and geometric distributions.
