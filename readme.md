# MatterGen Evaluation Scripts

A collection of standalone Python scripts for statistically evaluating crystal structures generated by MatterGen and comparing them with reference datasets.

## Features

Current functionality:

- Dataset summary
- Chemical composition statistics
- Number of atoms per structure
- Lattice parameter statistics
- Cell volume statistics
- Density statistics
- Space group distribution
- Publication-quality plots (PDF and PNG)
- CSV export of all computed metrics

Future scripts will include:

- Coordination numbers
- Bond-length statistics
- Bond-angle distributions
- Radial Distribution Functions (RDF)
- Structure validity checks
- Duplicate detection
- Novelty analysis
- Comparison with Materials Project, COD and OPTIMADE

## Usage

Example:

```bash
python 01_basic_statistics.py \
    --input ../../data/generated_structures \
    --output ../../data/results
```

or

```bash
python 01_basic_statistics.py \
    --input path/to/structures \
    --output path/to/results \
    --workers -1
```

### Command-line arguments

| Argument | Description |
|----------|-------------|
| `--input` | Input directory containing crystal structures |
| `--output` | Output directory |
| `--workers` | Number of CPU cores (`-1` = all available cores) |
| `--recursive` | Search subdirectories recursively |
